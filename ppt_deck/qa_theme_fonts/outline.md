## Slide 4: (No title)

Body:
- 传统鼓藻鉴定的三大瓶颈
- 平台设计重点围绕“识别难、管理散、分析弱”三类问题展开
- 形态相似，鉴定门槛高
- 鼓藻细胞形态差异细微，常需结合缢缝、半细胞轮廓、端部结构和纹饰进行人工判断。
- 样本批量增长，筛查效率低
- 多点位、多批次显微图像依赖人工逐张查看，难以适配连续监测和课程实验。
- 记录零散，复核链路断裂
- 识别结论、采样点、图片、置信度和报告分散保存，后续复核与生态分析成本高。

## Slide 7: (No title)

Body:
- 系统架构：三层科研数据中台
- 把前端体验、模型推理和数据沉淀拆成可独立演进的层级
- 前端交互层
- React + Vite 构建首页、图像检测、检测记录、分布图谱、物种档案和报告预览。
- 服务与模型层
- Flask API 负责上传、推理、记录查询与报告生成；YOLO11 输出类别、置信度和检测框。
- 数据沉淀层
- SQLite 保存检测记录、复核状态、采样点、报告结果，并连接公开分布与物种档案。
