## Slide 4: (No title)

Body:
- 行业痛点：传统鼓藻鉴定的三大瓶颈
- 与参考 PPT 的“行业困境”页对应，聚焦显微识别场景
- 形态相似，鉴定门槛高
- 鼓藻类群细胞形态差异细微，常需结合缢缝、半细胞轮廓、端部结构和纹饰人工判断。
- 批量样本，筛查效率低
- 多点位、多批次显微图像依赖人工逐张查看，难以适配课程实验和连续监测。
- 记录零散，复核链路断裂
- 识别结论、采样点、图片、置信度和报告分散保存，后续复核与生态分析成本高。

Body:
- 项目总览：“鼓藻鉴析”是什么？
- 并非单一识别模型，而是一套面向水生态样本的智能识别与数据归档平台
- 平台定位

- 系统载体
- React + Vite 前端，Flask + SQLite 后端，支持检测、记录、分布和报告。

## Slide 7: (No title)

Body:
- 系统架构：分层式水生态智能识别平台
- 从用户访问、统一接口到 AI 感知引擎和数据沉淀层层递进
- 前端交互层
- React + Vite 构建首页、图像检测、记录管理、分布图谱与物种档案等科研工作台页面。
- 服务与模型层
- Flask API 负责上传、推理、记录、报告与数据查询，YOLO11 模型输出类别、置信度和检测框。
- 数据沉淀层
- SQLite 保存检测记录、采样点、复核状态、报告结果，并连接物种档案与公开分布数据。
- 对应参考 PPT 的“系统架构 / 技术架构”章节
- 7/17
- 分层架构让交互体验、模型推理和数据归档可以独立演进，也便于后续扩展批量检测、生态分析和报告导出。

- 04
